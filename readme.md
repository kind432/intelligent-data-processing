# Intelligent Data Processing Service (MVP)

Интеллектуальный шлюз для обработки данных с устройств серии **Robbo
Protos**.\
Сервис выступает в роли *моста* между внешними командами управления и
MQTT-брокером, а также выполняет агрегацию и фильтрацию данных с
датчиков.

------------------------------------------------------------------------

## 🚀 Основные возможности

### Универсальная маршрутизация

-   Автоматическое обнаружение новых устройств по маскам топиков.

### Двусторонний мост команд

-   Принимает внешние команды в формате JSON через:

        robbo-protos-XX/...

-   Транслирует их в специфичные топики брокера:

        test@mail.ru/...

    в формате `ON/OFF`.

### Обработка данных

-   Вычисление скользящего среднего для числовых датчиков.
-   Сглаживание шумов измерений.

### Контроль состояния

-   Автоматическое определение статуса подключения устройств:
    -   `connect`
    -   `disconnect`

### Слоистая архитектура

Четкое разделение ответственности между: - транспортом (MQTT) -
бизнес-логикой (Service) - хранилищем (Repository)

------------------------------------------------------------------------

## 🏗 Архитектура проекта

Проект построен по принципам **Clean Architecture**.

    internal/
    ├── transport/mqtt   # Обработка сетевого протокола и маршрутизация сообщений
    ├── service          # Бизнес-логика и алгоритмы обработки
    ├── repository       # Потокобезопасное In-memory хранилище
    pkg/
    └── utils            # Парсинг MQTT-топиков (регулярные выражения)

------------------------------------------------------------------------

## 🛠 Конфигурация

Настройка осуществляется через файл:

    configs/config.yml

или переменные окружения.

### Пример конфигурации

``` yaml
mqtt_broker_address: "tcp://localhost:1883"
mqtt_username: "test@mail.ru"
mqtt_password: "your_password"
```

## 🔌 Примеры использования

### 1. Отправка команды (PowerShell)

Переключение реле на устройстве №1:

``` powershell
mosquitto_pub -h localhost -p 1882 -t "robbo-protos-01/switch/power_relay/command" -u "test@mail.ru" -P "pass" -m '{"power_relay": true}'
```

Сервис автоматически преобразует сообщение в:

    test@mail.ru/switch/robbo_protos_01_power_relay/command

со значением:

    ON

------------------------------------------------------------------------

### 2. Получение данных от датчика

Устройство публикует:

    test@mail.ru/sensor/robbo_protos_01_temp/state -> 25.5

Сервис создаёт два топика:

**Raw данные**

    robbo-protos-01/sensor/temp/raw -> {"temp": 25.5}

**Обработанные данные**

    robbo-protos-01/sensor/temp/proc -> {"proc_temp": 24.8}

(скользящее среднее значение)

## 📦 Развертывание

### Docker (рекомендуется)

Сервис оптимизирован для минимального размера образа через **Multi-stage
build**.

Сборка и запуск:

``` bash
docker-compose up -d --build
```

Просмотр логов:

``` bash
docker logs -f intelligent-data-processing
```
